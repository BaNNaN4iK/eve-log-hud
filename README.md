# EVE Log HUD

Настольное приложение для EVE Online (Windows): статистика боя, добычи и баунти из игровых логов,
оверлей поверх игры, состав флота, оценка предметов. Всё работает на вашем компьютере.

*Desktop companion for EVE Online (Windows): combat, mining and bounty stats from game logs, an in-game
overlay, fleet composition via ESI, item appraisal and a reprocessing calculator. Interface is in Russian.*

## Возможности

Ядро читает игровые логи и показывает итоги на странице приложения. Всё остальное — модули: их можно
включать, выключать, ставить и удалять по отдельности.

| Часть | Что делает |
|---|---|
| **Ядро** | Сессии боя, добычи и баунти: урон и DPS по оружию, входящий урон, ремонт, нейтрализация, РЭБ, руда и её цена, баунти в час. История, графики, выгрузка в CSV |
| `overlay` | Окно поверх игры: урон, ремонт, баунти, добыча, кто бьёт и кто держит, ручные сессии, окно флота |
| `fleet` | Флот напрямую из игры (ESI): состав, время во флоте, отлучки от босса, отметки ФК, история. **Отчёт о бое** по киллмейлам zKillboard: стороны, потери в ISK, эффективность, урон и добивания каждого пилота, корабли и оружие сторон, хронология, график |
| `appraisal` | Оценка предметов по ценам хабов (Jita, Amarr, Dodixie, Rens, Hek), как Janice |
| `reprocess` | Калькулятор переработки: что выйдет из руды, льда и модулей с вашими навыками, станция или структура с ригами, «переработать или продать», добыча прямо из сессии |
| `damage_types` | Каким уроном бьёт враг: ЭМ, термо, кинетика, взрыв |
| `alliance_auth` | Отправка итогов сессий на ваш сервер Alliance Auth (плагин Fleet Watch) |

Как устроены модули и как написать свой — [modules/README.md](modules/README.md).

## Установка

1. Скачайте архив `EveLogHUD-<версия>.zip` со страницы [Releases](https://github.com/BaNNaN4iK/eve-log-hud/releases/latest) и распакуйте в любую папку.
2. Запустите `EveLogHUD.exe`. Значок появится в трее, окно откроется само.
3. В игре включите запись логов: Esc → Чат → «Вести журнал в файле».

Windows может предупредить о неизвестном издателе (exe не подписан): «Подробнее» → «Выполнить в любом случае».
Пометку «скачано из интернета» с файлов программы приложение снимает само при запуске (без этого окно не открывалось).
Нужна Windows 10 или 11 с компонентом WebView2 (в Windows 11 он есть всегда).

**Модули.** Лежат в папке `modules` рядом с exe. Выключить — вкладка «Настройки» в окне программы.
Удалить — удалить папку модуля. Установить — распаковать архив модуля (`<id>-<версия>.zip`) в `modules`.

**Обновления.** Раз в 6 часов приложение сверяет версии с последним выпуском на GitHub. Новые версии модулей ставятся
кнопкой «Обновить» на вкладке «Настройки» (архив сверяется по SHA-256); о новой версии самого приложения там же появится ссылка.

**Флот.** На вкладке «Флот» нажмите «Подключить аккаунт EVE» — вход идёт на сайте CCP в браузере.
Состав флота игра отдаёт только боссу флота, поэтому отслеживать можно флот, где вы босс.

**Оверлей** виден, когда EVE работает в режиме «Окно» или «Окно без рамки».

**Папка логов** находится сама. Если нет (или логов несколько) — вкладка «Настройки» → «Папка логов»:
вставьте путь к `EVE/logs/Gamelogs` (можно к «Документам» или к папке `EVE` — нужная подпапка найдётся), «Проверить»,
«Сохранить» и перезапустите трекер. «Искать автоматически» возвращает поиск.

## Linux

EVE в Linux запускается через Steam (Proton), Wine, Lutris или Bottles — приложение ищет логи во всех этих местах
(`…/steamapps/compatdata/8500/pfx/drive_c/users/steamuser/Documents/EVE/logs/Gamelogs`, `~/.wine/…`, `~/Games/…`,
Bottles, дополнительные библиотеки Steam). Если папка в другом месте — укажите её на вкладке «Настройки».

1. Скачайте `EveLogHUD-<версия>-linux.tar.gz` со страницы [Releases](https://github.com/BaNNaN4iK/eve-log-hud/releases/latest)
   и распакуйте: `tar xzf EveLogHUD-*-linux.tar.gz`.
2. Запустите `./EveLogHUD/EveLogHUD`.

Что отличается от Windows:
- **Окно приложения** — встроенное, если установлен WebKitGTK (`gir1.2-webkit2-4.1`); иначе страница откроется в браузере.
- **Значок в трее** — если окружение рабочего стола его показывает (GNOME — с расширением AppIndicator). Без него
  приложение работает так же, выход — `Ctrl+C` в терминале или завершение процесса.
- **Оверлей** — нужен Tk (`python3-tk` / `tk`); прозрачность — при включённом композиторе. Глобальных клавиш
  (Ctrl+Alt+H, Ctrl+Alt+S) нет — кнопки на самом окне. В Wayland окна поверх полноэкранной игры могут не держаться —
  запускайте игру в окне.
- **Вход EVE для флота** хранится в файле с правами 600 (шифрования, как в Windows, нет).
- Данные — в `~/.local/share/EveLogHUD`.

Из исходников: `python3 eve_log_watcher.py --console` (только Python 3.9+, без пакетов) и страница http://localhost:47322.

## Данные и приватность

- Данные лежат в `%LOCALAPPDATA%\EveLogHUD` (или в папке `data` рядом с exe, если её создать).
- Страница приложения доступна только с этого компьютера (`127.0.0.1:47322`); чужие сайты не могут ни читать её,
  ни нажимать кнопки (проверка `Host` и `Origin`).
- Сеть: справочники и цены — с серверов CCP (`esi.evetech.net`, `images.evetech.net`), вход — `login.eveonline.com`,
  отчёт о бое — `zkillboard.com` (только когда вы его собираете).
  Проверка обновлений — `api.github.com` и `github.com` (выключить: `"update_check": false`).
  Отправка на Alliance Auth — только если вы сами его подключили. Логи, ники и статистика никуда больше не уходят.
- Токен входа EVE хранится зашифрованным средствами Windows и на другом компьютере не откроется. «Отключить аккаунт» удаляет его.
- Отключить всю сеть: `"online_enabled": false` в `config.json` (оценка и справочники перестанут работать).

## Запуск из исходников

Нужен Python 3.9+ (с python.org). Для ядра и модулей сторонние пакеты не нужны.

| Команда | Что делает |
|---|---|
| `python eve_log_watcher.py --console` | трекер с журналом в консоли (страница: http://localhost:47322) |
| `python eve_log_app.py` | приложение целиком: трей, окно, оверлей (нужны `pywebview`, `pystray`, `pillow`) |
| `python modules/overlay/overlay.py --demo` | оверлей с выдуманными числами |
| `python eve_log_watcher.py --backfill --days 90` | пересобрать историю из старых логов |
| `python eve_log_watcher.py --aa-connect URL KEY` | подключить Alliance Auth (`--aa-upload-history`, `--aa-disconnect`) |

Те же действия есть в bat-файлах в корне (`test_in_window.bat`, `start_overlay.bat`, `connect_aa.bat` и др.).

### Сборка exe

```
pip install pyinstaller pywebview pystray pillow
python build_app.py
```

Получится `dist/EveLogHUD/` (программа и папка `modules`), архив `dist/EveLogHUD-<версия>.zip`
и отдельные архивы модулей в `dist/modules/`.

### Тесты

```
cd tests
python -m unittest
```

Логику страницы тесты прогоняют в Node.js (если он установлен). На GitHub тесты запускаются автоматически
при каждой отправке изменений.

## Устройство

```
eve_log_watcher.py   ядро: чтение логов, сессии, история, локальный сервер
modkit.py            модули: поиск, включение, подключение к ядру
eve_log_app.py       настольное приложение: трей, окно, запуск трекера и оверлея
dashboard.html       страница приложения (вкладки модулей добавляются сами)
modules/<id>/        модули
tests/               тесты ядра и модулей
build_app.py         сборка exe
```

## config.json

| Ключ | По умолчанию | Описание |
|---|---|---|
| `logs_dir` | `""` | папка логов; пусто — найти автоматически (Windows: Документы, OneDrive; Linux: Proton, Wine, Lutris, Bottles). Меняется и на вкладке «Настройки» |
| `session_gap_seconds` | 300 | пауза, после которой сессия завершается |
| `min_session_seconds` | 20 | сессии короче считаются «короткими» |
| `poll_seconds` | 5 | как часто проверять логи |
| `import_days` | 30 | за сколько дней читать логи при первом запуске |
| `characters` | `[]` | только эти персонажи (пусто — все) |
| `web_port`, `lock_port` | 47322, 47321 | порты страницы и защиты от второго экземпляра. **47322 не менять**: на него настроен вход через EVE |
| `online_enabled` | `true` | запросы к ESI |
| `price_auto_refresh_minutes` | 60 | автообновление цен руды, пока открыта страница |
| `ore_prices_override` | `{}` | ручные цены руды, например `{"Veldspar": 15.5}` |
| `modules` | `{}` | включённые и выключенные модули, например `{"alliance_auth": false}` |
| `aa_url`, `aa_key`, `aa_live_upload` | | модуль `alliance_auth` |
| `esi_client_id` | `""` | свой Client ID приложения EVE вместо встроенного (модуль `fleet`) |
| `update_check`, `update_check_hours` | `true`, 6 | сверка версий с GitHub |
| `update_repo` | `""` | другой репозиторий для обновлений (`владелец/репозиторий`) |
